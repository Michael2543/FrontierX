Play the original *Conquest: Frontier Wars* on Linux without Wine. FrontierX ports
the original C and C++ engine while preserving retail gameplay.

> **A lawfully obtained retail installation is required to play.** Historical
> development resources in this source tree do not replace it.

## Highlights

- All **16 Terran campaign missions and the ending**, accepted through user playtesting.
- Native **Linux x86_64**, with SDL3 and Vulkan rendering.
- Original HUD, minimaps, animated portraits, speech, and movies.
- Fullscreen, save/load, original menus, and offline skirmish with AI.

**In development.** Campaign acceptance is recorded as of 2026-10-20. Broader
skirmish and ability testing, memory-leak fixes, and distribution review remain
open. Multiplayer and other native platforms are deferred.
[Detailed status →](docs/RETAIL_SINGLEPLAYER_FINALIZATION.md)
